# **App Name**: ERG Rénovation Numérique

## Core Features:

- Service Showcase: Showcase ERG Rénovation's range of services (apartment, studio, loft, etc.) with detailed descriptions and visuals.
- Project Gallery: Display a filterable gallery of completed projects, highlighting the quality and range of ERG Rénovation's work. The filtering allows by project type, room, budget and city.
- Before & After Comparisons: Implement before and after sliders to visually demonstrate the impact of ERG Rénovation's work on specific projects.
- Multi-Step Quote Form: An easy-to-use, multi-step form to request detailed project quotes, including file upload functionality for plans and photos.
- Local SEO Pages: Dynamically generate location-specific pages (Paris arrondissements and surrounding areas) with tailored content, project showcases, and FAQs.
- AI Content Tool Assistance: Leverage generative AI as a tool to generate initial drafts of content for service descriptions or location-specific pages. It incorporates project details and FAQs based on user input and Firestore data.
- CMS Integration with Firestore: Utilize Firestore as a CMS to manage all website content (services, projects, locations, blog posts) and user-submitted leads, with role-based access control.

## Style Guidelines:

- Primary color: Dark, desaturated blue (#2E3141) to evoke sophistication and trust.
- Background color: Very light gray (#F4F4F2), close in hue to the primary color, to provide a neutral backdrop that highlights content.
- Accent color: Muted orange/copper (#B87333) for CTAs and important elements, adding warmth and drawing attention.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, architectural aesthetic. Body font: 'Inter' (sans-serif) for clear, readable text.
- Minimalist icons representing services, locations, and project types. Consistent style throughout the site.
- Clean, grid-based layout with ample white space to ensure a premium and professional look.
- Subtle micro-interactions and transitions to enhance user experience without being distracting. Framer Motion used.
