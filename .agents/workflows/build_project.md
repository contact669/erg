# Build Project Workflow

Follow these steps to compile and build the ERG Rénovation Numérique project:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run TypeScript Static Analysis**:
   ```bash
   npm run typecheck
   ```

3. **Build Web Application**:
   ```bash
   npm run build
   ```
